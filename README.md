# مذاكرتي

- `index.html`: تطبيق الطلاب.
- `admin/index.html`: لوحة المسؤول المستقلة.

## حالة الربط

تم رفع النسختين الأصليتين كما هما للحفاظ على وظائفهما الحالية. تطبيق الطالب يخزن بياناته محلياً في المتصفح، ولوحة المسؤول الحالية تستخدم بيانات داخل الملف. لم يتم بعد ربطهما بقاعدة بيانات مشتركة أو تفعيل دخول إداري آمن.

المرحلة التالية: إعداد قاعدة بيانات مشتركة وسياسات وصول آمنة، ثم تحديث التطبيقين للمزامنة. لا تضع مفاتيح سرية أو صلاحيات إدارية داخل ملفات HTML العامة.
